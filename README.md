# 🚀 CollabSpace

CollabSpace is a platform that connects developers and startups to collaborate on projects efficiently.

---

## 📌 Features

* Developer & Startup Collaboration
*  Project Management
*  Communication between users
*  User Profiles with Image Upload
*  Rating & Review System (Future)

---

## 🛠️ Tech Stack

* Frontend: HTML, CSS, JavaScript
* Backend: Django
* Database: SQLite
* Hosting: (Optional - Azure / Vercel)

---

## ⚙️ How to Run the Project

### 1. Clone the repository

git remote add origin https://github.com/spgirija2006/CollabSpace.git

### 2. Navigate to project folder

cd collabspace-main/collabspace-main

### 3. Create virtual environment

python -m venv venv

### 4. Activate virtual environment

venv\Scripts\activate

### 5. Install dependencies

pip install django
pip install Pillow

### 6. Run migrations

python manage.py migrate

### 7. Run server

python manage.py runserver

### 8. Open in browser

http://127.0.0.1:8000/
